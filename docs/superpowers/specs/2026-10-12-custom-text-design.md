# 自定义文字信号

用户已确认：可修改的 Ctrl + Alt + T 快捷键（macOS 为 ⌃⌥T），鼠标位置文字气泡，120 个 Unicode 码点上限，5 秒显示，入房后自动同步。

独立的可聚焦输入窗口支持中文输入法和粘贴。Enter 发送，输入法选词期间不发送；Esc、失焦、暂停、显示器移除、加载失败或渲染进程退出均取消。输入时暂停原生手势监听，退出时结合设置页的按键捕获状态恢复，避免互相提前解除暂停。

文字使用纯文本 DOM 显示，复用现有姓名清理规则过滤控制与方向字符。空白文字不能发送。气泡限制数量、自动换行并限制在显示器边界内。

发送坐标记录打开窗口时的鼠标位置，以现有屏幕编号和归一化坐标在房间内同步。文字复用现有加密、重放保护、网络路由、成员静音、房间静音、暂停和接收限流。增加兼容消息类型，保留协议版本；旧版忽略文字，新版之间可收发，现有信号和表情继续可用。

快捷键复用原生 helper 的组合键判断和按键吞噬机制，在设置窗口复用 KeyCapture。与暂停快捷键相同的组合会被拒绝；用户更改快捷键时沿用系统占用检查。

验证：协议边界与 Emoji、原生组合键与暂停、房间加密收发与坐标映射/静音/限流、输入法 Enter、输入窗口 IPC 来源及生命周期、文字 DOM 安全与超时清理；执行 TypeScript、原生测试和构建。
